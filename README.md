# HR Management System - Oracle XE
A complete HR database system built in Oracle Express Edition.
Created using Oracle Express Edition (XE).

## Tables Included
- department.sql - Stores department details
- employees.sql - Stores employee master data
- leave_applications.sql - Manages salary records

 ## How to Run This Project
1. Open Oracle SQL Developer / SQL Plus
2. Connect to your XE database
3. Run files in this order:
    department -> employees -> leave_applications -> salary_ledger

## Tech Stack
- Database: Oracle XE
- Language: PL/SQL
